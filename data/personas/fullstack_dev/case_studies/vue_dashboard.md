# Vue.js reporting dashboard

## Context

Lumen Health (agritech) had a familiar problem: operators refreshed a legacy page to see sensor data.

## What I did

- Vue 3 composition API with live charts.
- Hand-built semantic, responsive markup.
- Pushed updates to the browser over a persistent connection.
- WebSocket stream for readings.
- Offline-friendly caching.

## Results

- 751 devices on one screen.
- Refresh delay from minutes to seconds.
- Operator errors down 34%.

Engagement: 13 weeks, finished 2024-04.

## Stack

Vue, JavaScript, REST API
