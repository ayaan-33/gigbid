# Internal admin panel

## Context

Orchid Analytics (marketplace) had a familiar problem: support engineers ran SQL by hand to fix customer accounts.

## What I did

- GraphQL API with audited mutations.
- Kept everything in their existing relational database with proper migrations.
- React admin with search and bulk actions.
- Permissions by role.
- Wrote the server side in JavaScript to share types with the frontend.

## Results

- Support handling time down 54%.
- Direct database access removed for 20 staff.
- 82 actions audited daily.

Engagement: 8 weeks, finished 2023-03.

## Stack

React, TypeScript, GraphQL
