# WordPress to Next.js migration

## Context

When I started with Kestrel Analytics, a architecture studio business, the WordPress site was slow and kept getting plugins hacked.

## What I did

- Content exported to a headless CMS.
- 301 redirect map for every old URL.
- Static generation with incremental rebuilds.
- Kept every URL and meta tag so search rankings held.
- Hand-built semantic, responsive markup.

## Results

- Organic traffic kept within 1% after launch.
- Load time down 67%.
- 568 pages migrated.

Engagement: 4 weeks, finished 2022-03.

## Stack

WordPress, Next.js, React
