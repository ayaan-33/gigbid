# Laravel API modernisation

## Context

A education client, Summit Partners, came to me because a 10-year-old PHP app nobody dared to change.

## What I did

- Added tests around critical flows first.
- Shipped it as a container image so their ops team could run it anywhere.
- Covered the critical paths with automated tests before refactoring.
- Moved to Laravel in slices.
- Containerised local development.

## Results

- Deploys went from monthly to 2 per week.
- Bug reports down 39%.
- 87% coverage on billing code.

Engagement: 11 weeks, finished 2024-06.

## Stack

PHP, MySQL, REST API
