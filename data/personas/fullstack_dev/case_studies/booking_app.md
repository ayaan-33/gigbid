# Appointment booking system

## Context

Summit Retail (dental clinics) had a familiar problem: front desks booked by phone and double-booked rooms.

## What I did

- Availability engine with resource constraints.
- Pushed updates to the browser over a persistent connection.
- SMS and email reminders.
- Kept the whole codebase strictly typed.
- Admin calendar with drag-and-drop.

## Results

- No-shows down 21%.
- 23 locations.
- Phone bookings down 44%.

Engagement: 3 weeks, finished 2020-08.

## Stack

React, Node.js, PostgreSQL, REST API
