# Marketing site and landing pages

## Context

A fintech startup client, Maple Partners, came to me because every landing page needed a developer.

## What I did

- Component library in Tailwind.
- Kept the whole codebase strictly typed.
- CMS-driven page builder.
- Kept every URL and meta tag so search rankings held.
- A/B test hooks for headlines.

## Results

- Page build time from days to 2 hours.
- Signup conversion up 8%.
- Core Web Vitals all green.

Engagement: 13 weeks, finished 2023-08.
