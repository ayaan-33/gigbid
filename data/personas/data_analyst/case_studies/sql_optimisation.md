# SQL query optimisation

## Context

When I started with Beacon Partners, a telecom business, month-end reports took hours to run.

## What I did

- Rewrote correlated subqueries as window functions.
- Added summary tables.
- Ran the models on their cloud warehouse.
- Reported confidence intervals rather than single numbers.
- Indexes chosen from query plans.

## Results

- Report runtime from 3 hours to 8 minutes.
- 12 queries tuned.
- Warehouse credits down 36%.

Engagement: 13 weeks, finished 2025-12.
