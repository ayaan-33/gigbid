# Onboarding chatbot

## Context

Kestrel Labs (insurance) had a familiar problem: new customers dropped off with unanswered setup questions.

## What I did

- Guided flows for the top 20 questions.
- Kept everything in their existing relational database with proper migrations.
- LLM fallback grounded in the FAQ.
- Wrapped it in a small typed Python web service.
- Handover to a human with full context.

## Results

- Onboarding completion up 15%.
- 74% of questions resolved by the bot.
- CSAT 4.34/5.

Engagement: 5 weeks, finished 2025-11.

Chatbot, LLM, Python
