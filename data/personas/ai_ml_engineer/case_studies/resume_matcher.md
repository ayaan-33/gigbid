# Candidate-job matching engine

## Context

When I started with Orchid Co., a HR tech business, recruiters keyword-searched resumes and missed good candidates.

## What I did

- Embedded resumes and job descriptions.
- Hybrid ranking with skill-taxonomy boosts.
- Bias checks on protected attributes before launch.
- Started from an open pretrained transformer checkpoint.
- Wrapped it in a small typed Python web service.

## Results

- Recruiter shortlist time down 60%.
- NDCG@10 0.78 on labelled searches.
- 146k resumes indexed.

Engagement: 11 weeks, finished 2022-07.

## Stack

Python, NLP, Vector DB, RAG
