# AI usage disclosure

This project was built with substantial help from an AI coding assistant (**Claude Code**, using
Anthropic's Claude), working in the student's repository under the student's direction.

## What the assistant did
- **Code:** proposed the architecture and wrote most of the code. That includes the simulator,
  the MCP servers, the agents and graphs, the RAG pipeline, the API, the web UI, the tests, the
  evals, Docker and CI.
- **Data:** wrote the data-generation scripts that produce the synthetic personas, clients and job
  augmentations. These are code-generated and template-based. The V6 context lines and V7 HyDE
  texts were generated by open models on the Groq free tier.
- **Debugging:** ran the evaluations and debugged failures, for example the free-tier rate limits,
  the SSE buffering, a cost double-count and the PII-masking regex.
- **Docs:** drafted the documentation, the report text and the demo script.

## What the student did
- **Decisions:** set the requirements and constraints (free-only, the hosting choice, the X2
  extension) and approved every plan step.
- **Accounts and keys:** created the accounts and API keys and kept them out of the repo.
- **Human evaluation:** provided the human labels for judge calibration and recruited the blind
  pairwise panel.
- **Live mode and deployment:** connected the live Upwork account and deployed to the Oracle VM.
- **Git and publishing:** reviewed and committed the code, published the Portfolio MCP package,
  posted the write-up and recorded the demo video.

## LLMs inside the product
These are separate from the coding assistant. They're open-weight models only: gpt-oss-20b and
gpt-oss-120b, Qwen3 and Llama Prompt Guard 2 on Groq's free tier, and qwen3:4b locally through
Ollama. Per-node choices are in `agent/config.yaml`.

## Integrity
- **Numbers:** every number in the README and report is produced by a script in `evals/runners/`
  and stored in `evals/results/`. CI checks that README numbers trace to those files.
- **Negative results** are reported as measured.
- **Synthetic data** is labelled `synthetic: true` everywhere (see DATA_CARD.md).
